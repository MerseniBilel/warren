# Changelog

All notable changes to Warren are documented here. This file aggregates the
core module; each submodule keeps its own changelog alongside its `go.mod`.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
Warren follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

While Warren is pre-1.0, **minor versions may contain breaking changes**, in
line with Go's semantic import versioning for `v0.x`. Breaking changes are
always listed under a **Breaking** heading with a migration note.

Entries below the `Unreleased` heading are generated from fragment files by
[changie](https://changie.dev) — do not edit them by hand. See
[docs/adr/0005-commits-and-changelog.md](docs/adr/0005-commits-and-changelog.md).
